Local & Air-Gapped RAG

An enterprise-grade, multi-tenant document intelligence system. Parse, chunk, and index PDFs, DOCX, and Text files locally using vector embeddings, FAISS indices, and Gemini-based Q&A context boundaries.

Core Technology Pillars

Cognify Docs leverages state-of-the-art architectures to achieve complete privacy, zero cross-tenant contamination, and sub-second retrieval speeds.

⚡

FastAPI REST Gateway

Designed with JWT-based session tokenization and secure password hashing. Fast, lightweight, and structured microservices endpoints.

🧬

Isolated Vector Stores

Ensures 100% data multi-tenancy. Document chunks map to unique folders `/vector_store/user_{user_id}`. No cross-account leakage.

🎯

Context-Locked Prompts

Strict LLM boundary formatting. Google Gemini API synthesizes answers using only the injected FAISS citations, completely avoiding hallucinations.

🛡️

Stream Safekeeping

Patched stream flushes preventing [Errno 22] crashes in headless or redirected console environments during AI model downloads.

RAG Execution Pipeline

Toggles between Ingestion and Query pathways to trace context and query embeddings flows.

1

Document Upload

User uploads a PDF, DOCX, or TXT file. Backend validates size and format restrictions.

2

Text Extraction & Chunking

Raw text is extracted and parsed. LangChain's splitter segments text into 500-character overlaps.

3

Embedding Generation

Local all-MiniLM-L6-v2 transformer model outputs 384-dimensional dense vectors.

4

FAISS Serialization

Vector arrays and metadata dictionaries (tagging document IDs) are saved in user directories.

1

Question Embedding

User queries the Chat Arena. Question is mapped to a vector in the same embedding space.

2

Metadata Pre-filtering

A Lambda metadata function pre-filters the search index based on the chosen document ID.

3

L2 FAISS Similarity Search

Retriever queries vector store to fetch the top 4 closest semantic chunks.

4

Context Injected Prompting

FastAPI formats a strict prompt containing context chunks and sends it to the Gemini API.

System Architecture & Schemas

Explore database relations, Entity schemas, and code directory boundaries.

USERS TABLE
  • id: INTEGER (Primary Key)
  • username: VARCHAR(50) (Unique)
  • hashed_password: VARCHAR(255)
  • created_at: DATETIME
DOCUMENTS TABLE
  • id: INTEGER (Primary Key)
  • filename: VARCHAR(100)
  • filepath: VARCHAR(255)
  • file_type: VARCHAR(10)
  • size_bytes: INTEGER
  • chunk_count: INTEGER
  • embedding_status: VARCHAR(20)
  • upload_date: DATETIME
  • user_id: INTEGER (Foreign Key)
CHAT HISTORY TABLE
  • id: INTEGER (Primary Key)
  • question: TEXT
  • answer: TEXT
  • timestamp: DATETIME
  • user_id: INTEGER (Foreign Key)
  • document_id: INTEGER (Foreign Key)
